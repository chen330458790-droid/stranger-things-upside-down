# 提示词模板

根据目标照片替换花括号内容，删除不适用的句子。提示词用于图像编辑，不是让工具重新创作相似场景。一个完整提示词由共享约束、共享空气模块、适用的人物处理模块、一个场景模板和必要的用户调整组成。

## 共享保真约束

```text
将编辑目标照片改造成《怪奇物语》颠倒世界侵入的写实场景。
输入角色：{目标图编号或路径}是唯一的构图与主体基底；{风格参考图}仅用于异世界特效、色彩和材质参考，不复制参考图的人物、地点、物件或标志。室外冷蓝调使用 skill 素材 `assets/cool-blue-hopper-reference.png`、`assets/cool-blue-eleven-reference.webp`、`assets/cool-blue-vecna-reference.webp`、`assets/cool-blue-upside-down-environment-reference.webp` 中最适合的 1–2 张，只参考深海军蓝暗部、青蓝／钢蓝中间调和冷蓝受光面。若天空足以容纳云中巨怪，必须额外输入 `assets/mind-flayer-cloud-reference.png`，且明确它只锁定夺心魔身份与轮廓。
原图主体：{实际观察到的人物、建筑、家具、车辆和其他关键物件}。
人物处理：{明确写出要保留的主体人物，或写明无人物主体并移除无关人群，使用下方适用模块}。对于应保留的人物，保持其原数量、身份、面部特征、发型、表情、姿势、手部动作、衣着与配饰。保持原建筑轮廓、场景布局、物件位置与形状、道路和地平线。保持原相机视角、镜头透视、主体比例、取景和宽高比。
改造环境、空气与照明，在以下指定区域添加特效：{实际可用区域}。保护以下主体区域：{脸、手、关键物件等实际位置}。
特效要与原照片匹配透视、尺度、遮挡、景深、清晰度和光照。人物与主要场景仍清楚可辨。皮肤与衣物保留真实材质，允许符合环境的新受光。
不新增标题、剧名标志、水印、边框或海报排版。保留原图具有辨识度的文字与标牌。不得新增人物、改变保留人物的动作或替换地点。
```

## 共享空气模块：细小密集孢子与淡薄雾气

默认用于室内、室外和人物近景；用户另有要求时调整。

```text
让大量细小、密集的不规则孢子弥散在全图可见空气中。它们像灰白、米白或极淡灰褐色的有机碎屑、微小薄片和短纤维，绝大多数仅为细点或短碎片，大小与轮廓自然变化。前景、中景、远景以及建筑、植被、地面和可见天空前都有分布，覆盖整个画幅的空气层，不仅出现在画面边缘、裂口附近或光束里；密度有轻微自然起伏，不形成均匀贴图。
近处孢子略清晰，远处更小、更淡，只有少量轻微失焦且仍保持细小；避免大型飘絮、硕大虚化光斑、规整圆点、雪花晶体、星星与亮片。孢子低透明度，随原场景光源微弱受光，不自行发亮。用更多细小颗粒形成密集感，保持人物五官、招牌文字与主体纹理可读，不形成白色噪点幕。
加入一点淡薄、半透明的冷蓝灰迷雾，轻轻弥散在地面附近和不同景深之间，形成不均匀的轻微层次。只轻柔散射局部光线、柔化远景，保留清晰的主体轮廓、表面纹理与可见冷蓝中间调；不要浓雾、烟墙或整图泛白，不通过整体压暗或冲淡反差代替薄雾。
```

## 无明确人物主体：移除无关人群

适用于以建筑、街道、风景或环境为主、无明确人物主体的照片。

```text
这张照片的主体是{实际建筑、街道或风景}，没有需要保留的主要人物。移除原图中的无关路人、游客、背景人群和远处人影，连同对应的人物投影、倒影及残留肢体一起清理。根据相邻区域自然补全被遮挡的地面、墙体与景物，匹配原透视、纹理和环境照明。保持建筑、道路、车辆、动物与其他物件的位置和形状，使场景呈现空旷、寂静的异世界氛围。不要新增人物或用雾气简单遮盖人群。
```

## 室外模板：冷黑暗部与橙红逆光

室外默认采用阴沉氛围与强烈冷暖分区。色彩参考输入为 Image {冷蓝参考图编号}，只借鉴色彩与照明：暗部是深海军蓝／蓝黑，中间调呈明显青蓝／钢蓝，受光面具有清楚但不刺眼的冷蓝环境光，整体保持电影感高反差并保留表面细节。除天空风暴亮区及室外地裂内部外，建筑、树木、车辆、道路、围栏和近景都应呈现这种可见冷蓝色相；冷调是色彩方向，不是单纯降低曝光。保留原图中间调亮度、纹理与主体可读性，以风暴云、局部阴影和冷暖反差营造压迫感。按原图适配亮区位置、天空面积和物体材质，不复制色彩参考图的人物、怪物、地点或构图。

```text

在原有天空中形成厚重风暴云与体积雾，将光集中于{原图远处低空、地平线附近或合适远景区域}。云雾被焦橙、琥珀色和暗红的内部光照亮，形成局部强烈暖亮区。暖光通过雾气扩散，向周围黑暗逐渐衰减。天空局部很亮，近景依然很暗，发光来自超自然风暴，不添加真实火海或熔岩。

{天空足够时：使用随提示词一同输入的固定怪物参考图 `assets/mind-flayer-cloud-reference.png`。在被照亮的远处云雾前呈现同一只夺心魔：保留参考图中巨大的中心躯干／脊柱形核心，以及向两侧和斜下方放射的多条粗长、弯折肢体，形成宽阔星状／蜘蛛状剪影。只允许云雾遮挡部分肢体并柔化边缘，不得改造成普通云团、单条触手、章鱼、龙、恶魔或其他怪物。怪物正面几乎不受光，以原建筑衬托尺度，不覆盖原图主要主体。参考图只规定怪物身份与轮廓，不复制其场景、构图或红色滤镜。}
暖色主要留在天空风暴亮区与室外裂隙内部；建筑、树木、车辆和保留主体呈可见冷蓝色调，而不只是黑色剪影。只允许裂隙附近有限的暖色反射，不用橙色轮廓光给大面积建筑或树木镶边。保留{原图已有灯光，如无则删除}作为有范围的局部光源，可中性或偏冷，不让暖光均匀照亮全景。
湿黑血肉藤蔓沿{原图真实建筑边缘、树干、墙角或地面接缝}附着生长，粗细分支有变化，遵循透视、表面附着和接触阴影。大部分隐在阴影中，只有少量湿润表面捕捉暗红反光，保留主体清楚轮廓。
```

## 仅限室外的地面裂隙模块

与室外模板组合使用；仅在原图实际可见且适合的室外实体地面加入。地面少则缩小，没有则省略，不用于水面或室内地板。室内带窗图仅可作用于原窗口实际可见的室外地面。

将 `assets/rift-black-flesh-red-membrane-reference.png` 作为材质参考输入；只提取黑肉与红色黏膜的颜色、结构和透光关系，不迁入参考场景或裂缝构图。

把本模块放在共享保真约束之后、天空和怪物等场景修饰之前。使用明确材质分层，避免仅描述“裂开地面＋红光＋藤蔓”。生成后执行 `SKILL.md` 的室外地裂交付检查。

```text
仅在{原图实际可见的室外道路、石板路或泥土地面区域}加入本次随机选定的{1–4}条不规则有机地面主裂隙，并在提示词中明确实际条数；裂隙可有少量次级分叉，或彼此分开形成数条。裂隙宽度和长度可醒目、宽大且彼此有变化，走向服从原地面透视，近宽远窄，并避开{保留主体、车辆和建筑地基}。保持原相机视角、建筑位置与大小，不拉远镜头、不缩小主体、不扩大地面来容纳效果；保留足够原地面区域以辨认材质和空间关系。
严格参考 Image {地裂材质参考图编号}：这是一道由厚黑肉和红色膜面组成的活体入口。裂口两条相对边缘都有连续、厚实、湿润的近黑肉质卷边，组织包住并遮盖大部分裸露石质断面，向两侧内壁连续延伸，具有不规则褶皱和筋腱层；以炭黑、黑曜石色为主，只捕捉克制的湿润高光及内缘极少红光。黑藤只是从组织中长出的附属物，不能用几根藤蔓搭在石沟边缘代替厚肉。碎石留在包肉外侧，与原路面自然衔接。禁止粉色裸肉、整圈红肉、香肠状组织和整齐等距肋条。
裂缝内部张拉着连续但局部破损的红色半透明黏膜，膜面湿润、黏滑、有层叠褶皱，内部可见细密网状纤维，局部有黏连拉丝连接两侧。膜面本身必须可见，不要只画悬空丝线。光从黏膜后方和深处透出，形成绯红、暗红至红橙的透光层次，少量最亮处可偏橙或琥珀色。厚肉和暗腔仍黑，清楚区分“湿黑肉质边缘”与“透红光的薄膜内部”。不生成熔岩河、普通石质峡谷、机械楼梯纹、均匀霓虹裂线或纯橙色发光填充。
零星黑色血肉藤蔓从裂口内壁与筋膜中生长，根部清楚连接组织，跨过破口边缘后贴着地面爬行，沿石缝分叉，少量攀附路缘或连接原建筑藤蔓。藤蔓湿润近黑、带暗红纤维，粗细与走向不规则，有接触阴影；越过碎石时短暂抬起后重新贴地。不出现直立蜷曲的触手、吸盘章鱼腕或悬浮肢体。
内部光只照亮碎块切缘、附近少量地面和藤蔓，迅速衰减回冷蓝阴影。建筑、树木、车辆和远离裂隙的路面继续保留可见冷蓝色相与原有明度层次，不因强调阴沉而整体压黑。少量薄烟或尘雾捕捉局部光，不遮蔽主体。保持原地面的其余材质与既定阴沉室外影调。
```

用户要求灰黑色藤蔓时附加：

```text
爬行和攀附表面的肉藤采用可见的石墨灰／炭灰黑中间调，湿润、有筋腱纤维和深黑凹槽。此颜色调整只针对藤蔓；裂口两侧与内壁仍有独立、连续的近黑厚肉包覆，内部仍是透红光的半透明膜面，不能因灰黑肉藤而退化成灰石沟与几根丝线。
```

```text

优先保持人脸、发型、衣物和手部动作。异世界变化集中于原背景的可用区域，以暗红环境光、少量边缘反光、背景附着藤蔓及共享空气模块的细小密集孢子和淡薄迷雾形成侵入感。孢子全图分布，人物面前透明度更低，避免遮挡五官。不要缩小人物来创造天空空间，不让怪物或藤蔓遮盖脸部。原背景景深保持，远处特效随背景一起虚化，但不产生大型孢子光斑。
```

## 有针对性的修正

修正时包含原图或适合的图像输入，并重新附上共享保真约束。以下句子按实际问题选用：

云中巨怪形态不符时，必须再次将固定参考图 `assets/mind-flayer-cloud-reference.png` 与目标图一同输入，并使用下方定向修正语句；修正后重新按固定图核对，不符就不通过。

- 人物漂移：恢复应保留主体在原图中的面部特征、姿态、衣着和手部动作，保留已正确融合的环境特效；不要恢复已按要求移除的无关人群。
- 人群清理不完整：继续清除指定移除的路人、游客、远处人影及对应投影、倒影和残肢，依据邻近纹理自然补全背景，保持原建筑与道路布局。
- 背景替换：恢复原建筑轮廓、家具位置、车辆与道路布局；把异世界变化限制到原天空、环境表面、指定破口和已选定的室外地裂区域。
- 只有红色滤镜：保留人物可读性，增加有体积的黑云、明确裂口或附着藤蔓，以及有来源的局部红光。
- 怪物像贴纸：将怪物部分藏入云层或穿过裂口，增加正确遮挡、接触关系、匹配光线和距离雾化。
- 太暗：适度恢复人物脸部、衣物与关键建筑的局部明暗细节，保留红黑风暴的阴影层次。
- 藤蔓盖住主体：疏开人物脸部、手部和关键物件周围的藤蔓，将感染集中到边缘、缝隙和次要表面。
- 特效过满：减少闪电和遮挡主体的前景藤蔓；孢子优先缩小尺寸、降低透明度并改善分布，保留用户要求的细小密集与全图覆盖，保持清晰的场景纵深。
- 孢子过大、过圆或过稀：将孢子缩为细点、微小不规则薄片和短纤维，增加数量与密度；清除大型飘絮、圆形虚化光斑和雪花。补全前、中、远景及全图可见空气中的分布，保留低透明度和主体可读性。
- 雾气过浓或全图泛白：降低雾的浓度与覆盖不透明度，只保留淡薄、分层、略偏冷蓝灰的轻雾，恢复主体轮廓、文字、表面纹理与原冷暖分区。
- 室外过亮或过红：恢复大面积墨蓝、炭黑暗部，将焦橙与琥珀暖光收束到远处云雾内部，压暗前景与地面反光，仅保留局部逆光轮廓，不用提亮全景来补细节。
- 冷暖对比不明显／建筑偏暖：将建筑立面、树木、围栏、道路和近景重新压为暗冷蓝、蓝黑与炭黑；把红橙暖色限制在天空风暴亮区和室外地裂内部，仅保留裂隙边缘极小范围的暖色反射。只调整色温与局部光溢，不改变原结构、怪物轮廓或裂隙形状。
- 冷调不明显：按 `assets/cool-blue-*-reference.*` 中实际输入的参考，将建筑、树木、车辆、道路和近景的阴影转为深海军蓝，中间调及受光面加入清楚的钢蓝／冷青蓝色相，保留当前曝光、细节与构图；不要只压低亮度或把环境变成黑色剪影，也不要复制参考图人物和场景。天空与地裂仍保持局部红橙暖色。
- 氛围仍不够阴沉：保留可读的中间调与冷蓝色相，通过加重云层、雾气、局部阴影和冷暖反差提升压迫感；避免通体降低曝光、压死暗部或给环境补暖光。
- 增加地裂数量：在原有实际可见的室外实体地面随机选定 1–4 条不规则裂隙，提示词写明本次数量；遵循地面透视并避开主体、车辆和建筑地基，裂隙可醒目宽大，保持空间关系自然。不得加在室内地板或水面。
- 巨怪过于清晰：降低正面照明和皮肤纹理可见度，以暗剪影呈现，让云雾遮住部分肢体并柔化边缘，保留巨大的尺度关系。
- 云中巨怪不是固定参考图中的夺心魔：严格依据随输入提供的 `assets/mind-flayer-cloud-reference.png` 重塑云中剪影，保留其中心躯干／脊柱形核心、宽幅放射的多条粗长弯折肢体及星状／蜘蛛状整体轮廓；移除任何龙、恶魔、章鱼、普通触手或无明确形体的云团特征。只改怪物外形与其云雾融合，保留已经正确的目标场景、构图、光影和其他效果。
- 地裂导致构图漂移：恢复编辑目标原有建筑大小、位置和镜头视角，只调整随机选定的 1–4 条裂隙在原图实际可见室外地面中的位置与尺度，不为效果创造更多前景空间。
- 裂口像熔岩或楼梯：按地裂材质参考恢复黑色肉质两侧及内壁、透红光的半透明黏膜和自然交织纤维，保留暗腔与不规则褶皱，消除熔岩填充与等距重复肋条。
- 肉质发红或缺少黏膜：再次输入 `assets/rift-black-flesh-red-membrane-reference.png`，将两侧及内壁恢复为湿润近黑肉质，只保留内缘微弱红色反光；内部增加清楚可见、局部撕裂的红色半透明膜面、网状纤维和少量黏连拉丝，让光从膜后透出。只修正颜色与材质，保留裂隙数量、位置、尺寸、透视及其他已正确效果。
- 爬出藤蔓变成触手：移除立起蜷曲的独立肢体，使稀疏藤蔓从裂口内壁生根、跨过边缘后贴地分叉并攀附真实表面，匹配原场景藤蔓材质。
- 室内误加地裂：移除室内地板上的裂隙、深沟与地底发光口，依据原图恢复完整地板及其透视与纹理，保留墙面或天花板的既定破口与感染藤蔓。
