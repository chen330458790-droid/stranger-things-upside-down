# stranger-things-upside-down

将真实照片转换为《怪奇物语》颠倒世界侵入的电影场景。一个包含提示词、视觉参考和成图检查规则的 Codex skill。

保留原照片的主体、建筑、物件、构图、透视与画幅，按实际场景加入异世界特效。

## 效果

- **冷暖光色**：建筑、道路与近景呈可见的冷青蓝／钢蓝色，天空风暴与裂隙内部保留局部红橙光。
- **室外**：根据原图天空空间加入固定参考造型的云中夺心魔；有合适实体地面时随机使用 1–4 条有机裂隙。
- **裂隙材质**：两侧和内壁是湿润黑色肉质，内部是透红光的半透明黏膜，带交织纤维、自然褶皱和局部黏连拉丝；藤蔓从内部贴地爬出。
- **室内与有屋顶场景**：使用局部墙面或天花板破口和魔王（Demogorgon）式怪物；室内地板不加入地裂。
- **空气**：细小、密集、不规则的孢子分布于全图可见空气，搭配淡薄的冷蓝灰迷雾。
- **人物与动物**：保留明确主体；无人物主体的建筑或风景照片可移除无关路人，动物继续保留。
- **检查与修正**：检查原图保真、怪物参考造型、黑肉与红膜、冷暖分区及孢子大小与分布。室外地裂必须实际查看两侧连续肉质包边和内部红色膜面；石沟搭藤、空沟加红丝网均不通过，自动定向修正后再检查，最多修正两次，仍不符时明确说明。
- **灰黑色肉藤**：可按用户要求采用石墨灰／炭灰黑中间调；单独保留裂口厚肉与红色黏膜结构，避免藤蔓颜色调整干扰裂口材质。

## 安装

下载本仓库，将 `skills/stranger-things-upside-down` 整个文件夹复制到你的 Codex skills 目录，通常为 `~/.codex/skills/`。

Windows 默认目录示例：

```text
%USERPROFILE%\.codex\skills\stranger-things-upside-down\SKILL.md
```

保留该文件夹中的 `agents/`、`assets/` 与 `references/`，以便读取造型、材质和色彩参考。若配置了自定义 Codex home，使用对应的 skills 目录。

## 使用

在支持图像编辑工具的 Codex 会话中附上目标照片并输入：

```text
用 $stranger-things-upside-down 转换这张照片。
```

也可以补充具体要求，例如保留人物、减少感染强度或调整裂缝数量。Skill 负责组织编辑要求和检查结果；实际图像生成需要会话提供可用的图像编辑工具。

仓库名称是 `stranger-things-upside-down`，安装后的 skill 名称仍为 `stranger-things-upside-down`。
